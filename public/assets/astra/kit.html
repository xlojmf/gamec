06 · Implementation

The game reads manifest.json for terrain, ocean, frame and token materials. 3D dice use reliable canvas pip textures; HUD dice use the SVG faces shown above. Missing materials retain procedural fallbacks. World PNGs use the built-in imagegen tool; the crest, resource icons and dice faces are original SVG assets. Controls remain live HTML, and numbers remain exact.
